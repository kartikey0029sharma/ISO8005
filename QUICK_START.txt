TROUBLESHOOTING
───────────────

❌ "Excel file not found"
→ Make sure the Excel file is in the data/ folder
→ Check filename matches exactly in script line ~15

❌ "Package not found" (e.g., readxl)
→ Go back to STEP 2 and install packages
→ Make sure you run the full package install code

❌ "Figures won't render in PDF"
→ Re-run scripts/03_visuals.R to regenerate PNGs
→ Check that figures/ folder contains all 6 PNG files
→ Then re-knit the Rmd

❌ "PDF won't knit / LaTeX error"
→ Install tinytex:
   tinytex::install_tinytex()
→ Or knit to HTML first to identify errors:
   rmarkdown::render("ISO8005_TAB_Report.Rmd", output_format = "html_document")

❌ "Word count is wrong"
→ Use https://wordcounter.net/ (it auto-excludes headers, figures, tables)
→ If too long: trim section 2.5 (Data Analysis) or 2.3 (Channel Strategy)
→ If too short: expand section 2.6 (Forecast) with more detail
